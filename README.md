# Disease Prediction System 🏥

A ML-powered disease prediction system that handles mixed symptoms from multiple categories without confusion.

## Features
- Multi-category symptom selection
- Probability-based predictions
- Medical history & lifestyle integration
- Explainable AI results

## Quick Start
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dataset
Synthetic dataset with 15 diseases, 25 symptoms, medical history, and lifestyle factors.

## Model
Random Forest with feature importance and probability outputs for handling mixed symptoms.
